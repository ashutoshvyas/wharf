# Browsing databases, servers, and websites

Use **Cards** or **List** on each screen to choose the layout. List view displays
compact rows with server addresses, status, relevant details, and the same
actions as the cards. Website details expand to show credentials and notes;
credentials remain subject to the existing role permissions.

**Sort** selects the field, with an ascending/descending toggle. The supported
list column headings also sort when clicked. Names with numbers and IPv4
addresses sort naturally (for example, `192.0.2.2` comes before `192.0.2.10`).

**Group → Server IP / host** collects entries with the same registered server
address, including separate server registrations with the same address. A server
registered by hostname displays that hostname; WHARF does not resolve DNS for
grouping. Databases and servers also support grouping by status.

Groups appear in address/name order with an item count. The selected sort applies
within each group, in either layout. Choose **No grouping** to return to one list.

View, sorting, and grouping preferences are remembered separately for each screen
in the current browser. The initial layouts remain cards for databases and
servers, and list for websites.
